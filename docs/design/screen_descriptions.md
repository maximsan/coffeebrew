# Screen Designs for Brew Master App

## 1. Onboarding & Authentication Screens

### Welcome Screen

- Dark background with gold accents
- App logo (coffee cup with stylized steam)
- Tagline: "Perfect your brew, one cup at a time"
- Swipeable intro cards explaining key features
- "Get Started" and "Login" buttons at bottom

### Sign Up Screen

- Email/password fields
- Social login options (Apple, Google)
- Toggle for subscription to newsletter
- Privacy policy and terms link
- Back button

### Preferences Selection

- Coffee drinking frequency
- Preferred brewing methods (multi-select)
- Flavor profile preferences
- Equipment available at home

## 2. Home Screen

- User profile icon in top-right corner
- Greeting with time-based message ("Good morning, [Name]")
- Daily challenge card ("Try a new brewing method today")
- "Continue where you left off" section with last viewed recipe
- Horizontal scrolling lists:
  - "Popular this week"
  - "Based on your taste"
  - "Quick brews (<5 mins)"
- Pull-to-refresh functionality
- Search bar with voice search option

## 3. Brew Methods Selection Screen

- Grid layout with iconic illustrations of brew methods
- Each method shows:
  - Method name
  - Difficulty level (1-5 coffee beans)
  - Average brew time
- Gold outline for methods user has tried before
- "PRO" badge for advanced methods
- "Add" button in top-right to create custom method
- Segmented control for "All" / "Favorites" / "Recent"
- Search and filter options

## 4. Recipe Detail Screen

- Hero image of final coffee
- Recipe name and creator
- Star rating with number of ratings
- Equipment needed with icons
- Recipe specs in cards:
  - Coffee amount (g)
  - Water amount (ml)
  - Water temperature
  - Grind size (visual indicator)
  - Total time
- Ingredients list with checkboxes
- Step preview with "Start Brewing" button
- Tabbed content for:
  - Instructions
  - Notes & Tips
  - Community Comments
  - Related Videos
- Action buttons:
  - Bookmark
  - Like
  - Share
  - Edit (if user's own recipe)

## 5. Brewing Process Screen

- Prominent brew method name and step number
- Timer display with circular progress
- Current instruction in large, clear text
- Visual representation of action (e.g., pouring animation)
- Progress bar showing overall completion
- Water/coffee ratio visualization
- Previous/Next step buttons
- Pause button for timer
- Option to add notes during brewing
- Skip option for experienced users

## 6. Bean Profile Screen

- Image of coffee bag (from scan or stock image)
- Roaster name and bean variety
- Origin details with small map visualization
- Processing method with icon
- Roast level visualization (slider from light to dark)
- Flavor notes with tag bubbles
- Barcode/QR code from scan
- Purchase information (price, date, location)
- Personal rating system
- Notes section
- Related recipes section
- "Brew with this bean" button

## 7. User Profile & Achievement Screen

- User avatar and username
- Level indicator ("Coffee Enthusiast Lvl 12")
- Progress bar to next level
- Statistics panel:
  - Coffees brewed
  - Beans tried
  - Methods mastered
  - Recipes created
- Badges gallery with locked/unlocked state
- Recent activity timeline
- "Coffee Passport" with stamps for each origin tried
- Friends/Following section
- Settings button

## 8. History & Journal Screen

- Calendar view with brew activity
- List view of recent brews with:
  - Date and time
  - Method used
  - Bean used
  - Rating given
- Filter options for history
- Search functionality
- Option to export data
- Insights panel showing trends
- Tasting notes journal entries
- "Repeat this brew" quick action

## 9. Community & Discovery Screen

- Featured brewers carousel
- Trending recipes section
- New content from followed users
- Challenges and contests
- "Coffee News" section with articles
- Community leaderboard
- Filter by brewing method, bean origin, etc.
- "Near Me" section showing local roasters

## 10. AI Recommendation Screen

- Personal taste profile visualization
- "Coffee DNA" graphic showing preference breakdown
- Suggested recipes based on history
- "Try Something New" recommendations
- Improvement suggestions for saved recipes
- Flavor comparisons between tried beans
- Learning path suggestions based on skill level
- "Why this recommendation?" explanatory notes
