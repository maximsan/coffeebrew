# Glossary

**V1** — the first release of Brew Master: iOS only, no accounts, no backend. Its scope is set in [docs/v1_phase0_scope.md](docs/v1_phase0_scope.md).

**Postponed past V1** — code that stays in the repo but the V1 app does not show. Each such file is listed in [docs/v2_backlog.md](docs/v2_backlog.md).
_Avoid_: out of scope (for code that exists), V2 (no V2 plan exists yet).

**Design-system project** — a project on claude.ai/design that holds preview pages of the app's components and theme. `/design-sync` uploads to it.
